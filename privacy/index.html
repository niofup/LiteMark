1. 概要

LiteMark 是一款本地 Markdown 编辑器。我们不为你的文档提供云端同步服务。文档由你通过系统对话框在本机打开与保存。我们不出售个人数据。

2. 我们是谁

  • 发布者 / 责任主体： Edward CCAO
  • 产品： LiteMark（桌面应用，经 Microsoft Store 分发）

3. 我们收集什么

类别 是否收集 说明
账号 / 注册 否 应用内无注册、不收集邮箱
文档正文 我们不收集 仅读写你打开或保存的本地文件，正文不上传至发布者
分析 / 崩溃遥测 否 无分析 SDK、无崩溃上报服务
广告标识 否 应用内无广告
支付数据 （发布者）否 买断与试用由 Microsoft Store 处理；账单与支付信息归微软。参见 Microsoft 隐私声明
发送给我们的设备标识 否 不运营会接收硬件 ID 的账号或许可服务器

4. 仅存在你设备上的数据

LiteMark 可能仅在本地保存：

  • 界面偏好（主题、侧栏、字体、编辑器模式等），存放于应用本地设置。
  • 应用数据目录（标识 com.litemark.editor；Windows 上通常为 %APPDATA%\com.litemark.editor\），可能包含：
    • 历史 / 自动快照（便于恢复此前版本）；
    • 仅存本机的诊断日志（若有）。
  • 最近打开的文件路径，仅用于本地「最近」列表。

可通过删除上述目录或卸载应用清除（卸载后应用数据可能仍残留，可手动删除）。

5. 网络行为

编辑功能以离线为主。仍可能发生的有限联网包括：

  1. 你文档中引用的内容：若 Markdown 含 http(s) 图片地址，内置 WebView 可能向第三方服务器请求这些资源；对方可能看到你的 IP 与常规请求信息。应用不代理、不记录这些请求。出于安全考虑，不支持内网 / localhost 等私网图片地址。
  2. Microsoft Store / 系统组件：安装、更新、许可及 WebView2 运行时更新由 Windows / Microsoft Store 处理。
  3. 打开外部链接：由系统浏览器与目标网站处理。

6. Microsoft Store 与购买

  • 分发、付款、退款与试用资格由 Microsoft Store 提供。
  • 微软可能依据 Microsoft 隐私声明 处理 Store 账号与购买相关个人数据。
  • Store 购买的支付卡信息不会由微软提供给发布者。

7. 儿童隐私

LiteMark 面向通用生产力场景，不面向 13 周岁以下（或你所在地区法定最低年龄）儿童。我们不会故意收集儿童个人信息。

8. 你的选择

  • 不希望产生本地读取或第三方图片请求时，请不要打开相应文档或外链图片。
  • 卸载应用可停止使用；删除应用数据目录可清除本地快照与设置。
  • 购买与退款请通过 Microsoft Store 与微软支持渠道处理。

9. 政策变更

功能变化时我们可能更新本政策，并修改文首「最近更新」日期。如有重大变更，将在 Store 更新上线前或同步在此说明。

1. Summary 概要

LiteMark is a local Markdown editor. We do not operate a cloud service for your documents. Your notes are opened and saved on your device through the system file picker. We do not sell personal data.

2. Who we are 我们是谁

  • Controller / Publisher: Edward CCAO
  • Product: LiteMark (desktop application, distributed via Microsoft Store)

3. What we collect 我们收集什么

Category Collected? Details
Account / registration No No sign-up; no email collection in-app
Document content Not by us LiteMark only reads/writes files you open or save. Content is not uploaded to the publisher.
Analytics / crash telemetry No No analytics SDK, no crash reporting service
Advertising identifiers No No ads in the app
Payment data No (publisher) Purchase and trial are processed by Microsoft Store. Billing data goes to Microsoft, not to us. See Microsoft privacy statements.
Device IDs sent to us No No account or license server operated by the publisher receives hardware IDs

4. Data stored on your device 仅存在设备上的数据

LiteMark may store the following locally only:

  • UI preferences (theme, sidebar, fonts, editor mode, etc.) in local application storage.
  • Application data folder for app identity com.litemark.editor (on Windows, typically %APPDATA%\com.litemark.editor\), including:
    • History / auto-snapshots of documents you edit
    • on-device diagnostic logs (if any)
  • Recently opened file paths for a local recent list only.

Clear snapshots and settings by deleting that folder or uninstalling the app (Windows may leave app-data leftovers; delete the folder manually if needed).

5. Network activity 网络行为

Editing works offline. Limited network use can still occur:

  1. Content you reference: If a document contains http(s) image URLs, the embedded web view may request those URLs. Third-party servers may see your IP address. LiteMark does not proxy or log those requests. Private-network image URLs (LAN/localhost) are intentionally not supported.
  2. Microsoft Store / OS components: Install, update, licensing, and WebView2 runtime updates are handled by Windows / Microsoft Store.
  3. External links: Handled by your browser and the destination site.

6. Microsoft Store and purchases Microsoft Store 与购买

  • Distribution, payment, refund, and trial entitlement are provided by Microsoft Store.
  • Microsoft may process personal data for Store accounts and purchases under Microsoft Privacy Statement.
  • The publisher does not receive your payment card details from Microsoft for Store purchases.

7. Children’s privacy 儿童隐私

LiteMark is a general-purpose productivity tool and is not directed at children under 13 (or the minimum age in your region). We do not knowingly collect personal information from children.

8. Your choices 你的选择

  • Avoid opening documents or remote images if you do not want related local or third-party access.
  • Uninstall to stop all use; delete the app-data folder to remove local snapshots/settings.
  • Use Microsoft Store support for purchase and refund issues.

9. Changes to this policy 政策变更

We may update this policy when features change. The “Last updated” date will change. Material changes will be reflected here before or when a Store update ships.
